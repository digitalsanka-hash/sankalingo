1 · Sebelum mulai

SankaLingo GO adalah situs statis: tidak ada kode server, tidak ada proses build, tidak ada basis data yang wajib. Artinya ia bisa ditaruh di hosting statis mana pun dan tetap jalan penuh — termasuk saat pengunjung sedang luring.

Yang diunggah±2,2 MB dalam 115 berkas
Yang TIDAK diunggah.venv-tts/ (4,6 GB), tools/, PAKET LENGKAP/, server.js
Proses buildtidak ada — berkas disajikan apa adanya
Basis datatidak wajib; hanya untuk selaras antar perangkat

Jangan lewatkan ini. Folder aplikasi berisi .venv-tts/ sebesar 4,6 GB — sisa lingkungan PyTorch dari rencana lama yang sudah ditinggalkan. Kalau ikut terunggah, deploy akan gagal atau memakan waktu sangat lama. Berkas .vercelignore dan .gitignore sudah menyingkirkannya untukmu, tetapi periksa sekali dengan git status sebelum commit pertama.

Yang berubah dari rencana lama

Rencana awal merekam seluruh materi suara memakai F5-TTS. Rencana itu sudah ditinggalkan karena bobot modelnya berlisensi nonkomersial — dan itu dulu menjadi penghalang terbesar untuk menjual aplikasi ini.

Akibatnya menguntungkan: aplikasi sekarang memakai Web Speech API bawaan peramban. Tidak ada satu pun berkas audio, dan tidak ada kewajiban lisensi TTS sama sekali. Aplikasi bebas dijual.

Yang masih perlu dicantumkan atribusinya: data goresan kana dan hanzi dari KanjiVG (CC BY-SA 3.0), serta penyangkalan merek dagang untuk nama ujian (TOEFL, IELTS, JLPT, dan seterusnya). Keduanya sudah terpasang di NOTICE.md dan halaman Panduan aplikasi. Goresan Arab dibangkitkan dari huruf Amiri berlisensi SIL OFL, jadi bebas dipakai.

2 · Deploy ke Vercel

Ada dua jalur. Jalur A lewat GitHub — setiap kali kamu mengubah materi lalu git push, situs ikut diperbarui sendiri. Jalur B tanpa GitHub, lebih cepat untuk sekali coba tetapi pembaruannya manual.

Jalur A — lewat GitHub (disarankan)

  1. Siapkan repositori lokal 
    cd "D:/ASDP/02. PROJEK/files/fasih"
git init
git add .
git commit -m "SankaLingo GO siap deploy"

    Sebelum commit, jalankan git status dan pastikan .venv-tts tidak disebut.

  2. Buat repositori kosong di GitHub

    Beri nama bebas, misalnya sankalingo. Jangan centang "Add a README" — repositorinya harus benar-benar kosong.

  3. Dorong kode ke GitHub 
    git remote add origin https://github.com/NAMA-ANDA/sankalingo.git
git branch -M main
git push -u origin main
  4. Impor di Vercel

    Buka vercel.com → Add New → Project → Import, pilih repositori tadi. Isi seperti tabel di bawah, lalu tekan Deploy.

IsianNilai
Framework PresetOther
Root Directory.
Build Commandkosongkan
Output Directorykosongkan
Install Commandkosongkan

Kalau Vercel memaksa mengisi Build Command, isi dengan echo statis. Perintah itu tidak melakukan apa pun dan aman — yang penting jangan biarkan Vercel menebak sendiri, karena ia bisa mengira ini proyek Node dan mencoba menjalankan server.js.

Sekitar satu menit, situs hidup di nama-proyek.vercel.app.

Jalur B — tanpa GitHub

npm i -g vercel
cd "D:/ASDP/02. PROJEK/files/fasih"
vercel

Ikuti pertanyaannya. Saat ditanya apakah ingin mengubah pengaturan build, jawab no. Untuk menerbitkan versi produksi:

vercel --prod

Yang sudah disiapkan untukmu

BerkasGunanya
vercel.json Aturan cache dan pengamanan dasar. index.html, sw.js, js/, dan data/ sengaja tidak disimpan lama.
.vercelignore Menyingkirkan .venv-tts/, tools/, PAKET LENGKAP/, server.js.
.gitignore Sama, untuk sisi Git.

Kenapa kode sengaja tidak di-cache lama? Kalau js/ dan data/ disimpan berbulan-bulan oleh peramban pengunjung, mereka terjebak di versi lama dan tidak ada cara memperbaikinya dari jauh. Kemampuan luring tetap utuh, karena pekerja layanan (sw.js) punya cadangannya sendiri.

Memakai domain sendiri

Vercel → Project → Settings → Domains → Add. Tambahkan rekaman DNS yang ditampilkan di penyedia domainmu. Sertifikat HTTPS dipasang otomatis, gratis.

3 · Supabase

Perlukah?

KeadaanJawaban
Dipakai sendiri, satu perangkat Tidak perlu. Lewati seluruh bagian ini.
Dijual atau dipakai banyak orang Perlu, kalau kamu ingin kemajuan pengguna selamat saat mereka ganti HP.

Tanpa Supabase, aplikasi tetap jalan penuh — kemajuan tersimpan di localStorage peramban. Yang hilang hanya kemampuan berpindah perangkat. Kartu penyelarasan di halaman Pengaturan otomatis tersembunyi selama Supabase belum dikonfigurasi, jadi pengguna tidak melihat pilihan yang tak berguna baginya.

Langkah

  1. Buat proyek

    Buka supabase.com → New Project. Pilih wilayah Southeast Asia (Singapore) — paling dekat dari Indonesia. Simpan kata sandi basis data yang kamu buat; aplikasi tidak memakainya, tetapi kamu akan membutuhkannya kalau kelak ingin masuk lewat psql.

  2. Jalankan skema

    Buka SQL Editor → New query, tempel seluruh isi supabase/skema.sql, tekan Run. Skrip ini membuat satu tabel kemajuan, menyalakan Row Level Security, dan memasang empat aturan akses. Aman dijalankan berulang kali.

  3. Pastikan RLS benar-benar menyala 
    select tablename, rowsecurity from pg_tables
where schemaname = 'public' and tablename = 'kemajuan';

    Kolom rowsecurity harus bernilai true.

  4. Nyalakan masuk dengan email

    Authentication → Providers → Email: pastikan aktif. Matikan Confirm email supaya pengguna bisa langsung masuk dengan kode tanpa langkah konfirmasi terpisah.

  5. Salin kunci ke aplikasi

    Settings → API, ambil Project URL dan kunci anon public. Tempel ke js/awan-config.js:

    export const AWAN = {
  url:  'https://abcdefghijkl.supabase.co',
  anon: 'eyJhbGciOi…'
};
  6. Deploy ulang

    git push atau vercel --prod.

Kunci mana yang boleh dipasang. Kunci anon memang dirancang untuk dipasang di sisi peramban dan boleh dilihat siapa pun — yang menjaga data adalah Row Level Security, bukan kerahasiaan kunci. Yang tidak boleh dipasang di sisi peramban adalah kunci service_role: kunci itu menembus seluruh RLS dan bisa membaca data semua pengguna.

Bagaimana penggabungan bekerja

Ini bagian yang paling menentukan, karena salah rancang berarti kemajuan pengguna hilang. Penggabungan dilakukan per bidang, bukan timpa-menimpa:

BidangAturan
XPdiambil yang tertinggi — bukan dijumlah, supaya tidak menggelembung tiap kali diselaraskan
Pelajarangabungan; kalau ada di dua sisi, ambil nilai tertinggi
Kartu hafalanambil yang riwayat ulangannya lebih panjang
Riwayat harianper tanggal ambil yang tertinggi, tidak dijumlah
Catatan & penandagabungan, tanpa kembar

Artinya: belajar di ponsel saat laptop sedang mati tidak akan menghapus apa pun saat keduanya bertemu. Penggabungan juga idempoten — menggabung dua kali hasilnya sama dengan sekali.

Cara memakainya sebagai pengguna

Halaman Pengaturan → Selaraskan antar perangkat: masukkan email, terima kode enam angka lewat email, masuk. Di perangkat kedua, masuk dengan email yang sama. Tidak ada kata sandi yang perlu dibuat atau diingat.

4 · Setelah hidup

Periksa satu per satu

  • Situs terbuka di alamat .vercel.app
  • Berpindah bahasa berjalan — coba #/de/kurikulum dan #/ja/kanji
  • Tombol suara berbunyi
  • Matikan internet, muat ulang — aplikasi tetap terbuka
  • Di ponsel muncul tawaran "Tambahkan ke Layar Utama"
  • Kalau memakai Supabase: masuk di dua perangkat, pastikan kemajuan berpindah

Saat memperbarui materi

Ubah berkas di data/, lalu naikkan nomor versi di sw.js:

const VERSI = 'fasih-v10';   // dari v9

Tanpa langkah ini, pengguna lama akan terus melihat materi versi sebelumnya sampai cadangan luringnya kedaluwarsa sendiri. Ini kesalahan yang paling sering terlewat.

Biaya

LayananPaket gratisCukup untuk
Vercel Hobby100 GB lalu lintas/bulanribuan pengunjung

Satu jebakan biaya-nol: proyek Supabase gratis dijeda otomatis setelah tujuh hari tanpa aktivitas. Membangunkannya cukup dengan membuka dasbornya, tetapi selama dijeda penyelarasan akan gagal. Kalau aplikasi dipakai orang lain, pastikan ada permintaan sekali sepekan — atau naikkan ke paket berbayar.

5 · Kalau ada yang gagal

GejalaSebab & penanganan
Deploy sangat lama atau gagal kehabisan ruang .venv-tts/ (4,6 GB) ikut terunggah. Pastikan .vercelignore dan .gitignore ada di akar folder, lalu ulangi.
Situs terbuka tetapi halamannya kosong Vercel mengira ini proyek Node dan mencoba mem-build. Setel Framework Preset = Other dan kosongkan Build Command.
Perubahan materi tidak muncul Pekerja layanan menyajikan berkas lama. DevTools → Application → Service Workers → Unregister, lalu Storage → Clear site data. Untuk pengguna lain: naikkan VERSI di sw.js.
"Server tidak terjangkau" saat menyelaraskan Alamat proyek Supabase salah di js/awan-config.js, atau proyeknya sedang dijeda. Buka dasbor Supabase untuk membangunkannya.
Kode enam angka tidak sampai Periksa folder spam. Kalau tetap tidak ada: Authentication → Providers → Email pastikan aktif. Paket gratis Supabase membatasi jumlah email per jam.
Masuk berhasil tetapi kemajuan tidak berpindah Hampir selalu RLS belum menyala atau skema belum dijalankan. Ulangi langkah 2 dan 3 di bagian Supabase.
Suara tidak keluar di ponsel Bukan masalah deploy. Web Speech API butuh sentuhan pengguna lebih dulu, dan suara bahasa asing bergantung pada apa yang terpasang di perangkat itu. Halaman #/<kode>/suara menampilkan keadaan sebenarnya.
